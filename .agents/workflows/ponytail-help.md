# Ponytail Help

Show the ponytail quick reference card.

Levels:
- `/ponytail lite`: build what's asked, name the lazier alternative in one line
- `/ponytail` (full, default): YAGNI → stdlib → native platform → one line → minimal working
- `/ponytail ultra`: deletion before addition, challenges the requirement before building
- Deactivate with 'stop ponytail', 'normal mode', or `/ponytail off`

Commands:
- `/ponytail-review`: over-engineering review of the current changes
- `/ponytail-audit`: whole-repo over-engineering audit
- `/ponytail-debt`: harvest ponytail: comments into a tracked ledger
- `/ponytail-gain`: measured-impact scoreboard from benchmark
- `/ponytail-help`: this card
